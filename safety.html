1win account security checklist

Keep the account, email or phone, and payment method in your control.

Use a unique password

Use a long password you do not reuse on email or other betting sites. A password manager helps.

Enable 2FA

Turn on 2FA where it is offered, store recovery codes, and ignore login prompts you did not start.

Verify the address

Start from 1winex.com, then use Login or Registration. Skip lookalike domains, search ads and chat links.

Secure the device

Use a screen lock and current software. Do not save a login on a shared device.

Review account activity

Check unfamiliar logins and transactions. End other sessions if the account lets you.

Submit KYC privately

Upload documents only from the signed-in account, and only the files it asks for.

Support should not ask for a password or one-time code. Treat requests for card security codes or wallet recovery secrets as suspicious.
